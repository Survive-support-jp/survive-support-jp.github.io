# チラシ流入向け「3日間パック」LP 設計

## 目的

ポスティングしたチラシのQRコードまたはURLから来た飯能市周辺の家庭が、30秒以内に次の4点を理解し、メール相談へ進める状態にする。

1. サバイブが売るものは「防災用品の箱」ではなく、家に置き、期限まで管理できる3日間分の備えである
2. 1人分の中身と数量
3. 基本価格と人数ごとの目安
4. 相談は無料で、当日に購入判断する必要がないこと

一次CTAは `無料で備えを確認する` とし、既存のメール相談導線へ接続する。サイト上での申込み・決済・契約は扱わない。

## ビジュアルモデル

- 生活用品ブランドのような、白い余白と大きな実物写真を中心にした静かな見せ方
- 防災セット販売ページのような、中身・数量・価格を迷わせず伝える情報設計
- 上記をそのまま模倣せず、サバイブ独自の `訪問設置 + 期限管理` を商品写真の直後に見せる
- 深緑を基本色、赤を価格とCTAだけのアクセントにする
- 既存のナビゲーションと関連サービスへの導線は、チラシ流入LPでは主CTAより弱くする

## 対象と前提

- 対象: 飯能市・日高市・入間市周辺で、チラシを見た個人世帯
- 主な不安: 水の置き場所、非常用トイレ、食料、賞味期限管理
- 商品: 1人分の3日間パック
- 価格: 1人 29,000円、2人 54,000円、3人 79,000円、4人 104,000円（税込目安）
- 標準構成: 保存水9L、尾西の白飯5食、日本ハム陸上自衛隊戦闘食糧モデル4種、井村屋えいようかん5本、BOS非常用臭わないトイレ15回分、ラジオ付きライト、保管箱、期限管理ラベル
- 乾電池は標準構成に含めない

## ページ構成

### 1. ファーストビュー

- 見出し: `家に3日分の備えを、置ける状態まで整える。`
- 商品写真: `assets/3day-pack/3day-pack-product-photo.png` を使用
- 補足: 聞き取り、訪問設置、期限管理まで含むことを明示
- CTA: `無料で備えを確認する`
- 価格の最小表示: `1人 29,000円（税込目安）`
- モバイルでは、見出し、価格、CTA、商品写真が最初の画面で読める配置にする

### 2. 「届くもの」

- 商品写真の近くで、全構成と数量を短い一覧で表示
- 実際のブランド名を出すのは、採用品が確定している食料・トイレ・ラジオに限る
- 水は `長期保存水 500mL × 18本（9L）` と表示する
- 水 / 食料 / トイレ / 光と情報 / 保管の5区分を、短い数量表示で横並びにする

### 3. 商品ではなくサービスとしての価値

- 水は低い場所に置く
- 既存備蓄を捨てずに活かす
- 期限を一覧化し、60日前を目安に補充を案内する
- 余計なものは外して見積する

### 4. 料金

- 人数別の価格を一行で見せる
- 価格には、備蓄品・聞き取り・訪問設置・期限管理を含むと明記する
- 追加水、衛生用品などは都度見積とする

### 5. 相談から納品まで

1. メールで人数・既存備蓄・置き場所の悩みを送る
2. 無料の聞き取りと見積
3. 日程調整後に納品・設置
4. 期限一覧を渡し、補充時期に連絡

### 6. FAQ と最終CTA

- 今ある備蓄がある場合
- 置き場所がない場合
- 対応地域
- 今日決める必要がないこと
- CTAはメール相談のみに統一する

## 実装方針

- `bousai/index.html` をLPとして更新する
- 動的スクリプトによる旧価格・旧構成の上書きではなく、HTML本文、構造化データ、メタ説明、診断計算を同じ値に揃える
- 親サポート等の関連サービスへの導線は、主CTAより弱くするかLPから外す
- モバイルでは商品写真、価格、CTAがスクロールせず見える領域に入るようにする

## 検証

- HTML本文・構造化データ・メタ説明に `35,000円`、`甘味3本`、`乾電池`、`27,000円` が残らないこと
- 価格表示テストと診断テストが通ること
- モバイル幅でCTA、29,000円、商品写真が読めること
- QRとメール導線が動作すること
