# 3日間サバイブパックの価格価値表示

## 目的

35,000円を単なる防災セットの箱代に見せず、備蓄品・訪問設置・最長5年間の期限管理を含むサービス価格として伝える。

## 決定事項

- 商品名は `3日間サバイブパック`。
- 1人分は `35,000円（税込目安）`。
- 価格横に `備蓄品一式＋訪問設置＋最長5年間の期限管理` を置く。
- 3人分の89,000円には `最長5年間で1日あたり約49円` を添える。
- Amazonなど他社名は表示しない。
- 「最長5年間」は、納品後に期限台帳を作成し、期限60日前を目安に補充連絡する既存運用を指す。補充品の代金は含まない。

## 表示対象

- `/bousai/` の料金カード
- `/bousai/diagnosis/` の診断結果に出る価格説明
