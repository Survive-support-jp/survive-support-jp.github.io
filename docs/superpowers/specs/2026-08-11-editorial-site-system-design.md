# Survive editorial site system design

## Goal

防災用品の一覧ページではなく、「家に置ける備えを整える」サービスを体験として理解できる、スマホ主導の1ページサイトに刷新する。

## Visual system

- 背景はアイボリー、文字は深緑、行動ボタンだけ珊瑚色。
- 写真は生活空間または実商品を大きく使い、画像の上に透過なしの白ラベルを重ねる。
- セクションの英字見出し、罫線グリッド、小さなカードの反復は使わない。
- CTAは幅広い半円形のボタンに統一する。
- 他社のロゴ、写真、コピー、書体、色指定は使わない。

## Page storyboard

1. 生活空間のヒーロー: 地域、サービス種別、短い見出し、無料相談CTA。
2. 商品紹介: 実商品の写真、3日間パック、1人29,000円から。
3. 中身: 水、食、トイレ、光と情報を大きな見出しと数値で順に見せる。
4. サービス: 置き場所、今ある備蓄、期限管理を生活シーン背景に重ねる。
5. 料金: 1〜4人の価格を大きな数字だけで見せる。
6. 流れ: 相談、聞き取り・見積、納品・設置、期限管理を縦の番号で見せる。
7. FAQと最終CTA: 不安を解消してメール相談へ進める。

## Constraints

- 価格と商品構成は現行のまま維持する。
- メール相談のURL、質問、既存のFAQ内容は維持する。
- 390px幅を最優先し、PCは余白を広く取る同じデザイン言語で表示する。
- 外部ライブラリを追加しない。

## Acceptance checks

- すべての主要セクションが `editorial-` クラスで新しい表示規則を持つ。
- 390pxと1440pxで読めることをスクリーンショットで確認する。
- 商品・価格・相談の回帰テストが通る。
