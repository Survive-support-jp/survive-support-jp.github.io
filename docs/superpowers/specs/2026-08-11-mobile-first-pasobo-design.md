# Mobile-first consultation LP design

## Goal

スマホでチラシから訪れた人が、最初の画面で「自宅向けの防災備蓄サービス」「29,000円から」「無料で相談できる」を理解し、相談導線を押せるようにする。

## Direction

CLASのように、スマホ1画面を暮らしの写真で大きく使い、短いコピーをラベルとして重ねる。サバイブの実商品写真は前面に置き、内容の正確さを保つ。CLASのロゴ、書体、写真、コピー、色は使用しない。

## Mobile first view

- ヘッダーはロゴだけを置き、ヒーロー内の生活シーンと一体化させる。
- 生成した明るい玄関・収納の生活シーンを、ヒーロー背景として使う。
- 対応地域、サービス種別、見出しを白いラベルとして重ねる。
- 実商品の写真をヒーロー下部に重ねる。
- 価格は小さなラベル「1人 29,000円から」として商品写真の近くに置く。
- 画面下には同じメール相談へ進む固定CTAを設置する。
- 既存の「中身」「サービスの違い」「価格」「流れ」「FAQ」は内容を維持する。

## Desktop

- 既存の2カラム構成は維持する。
- スマホ専用の固定CTAは表示しない。

## Constraints

- 表記は1人29,000円、2人54,000円、3人79,000円、4人104,000円を維持する。
- 商品構成は水9L、白飯5食、おかず4食、えいようかん5本、BOS非常用トイレ15回分、ラジオ付きライト、保管箱・期限一覧を維持する。
- CTAは `#contact` へ進み、メール相談の内容は変更しない。
- 外部ライブラリは追加しない。

## Acceptance checks

- 390px幅で見出し・価格・CTAが横にはみ出さない。
- 390px幅で固定CTAが表示され、`#contact` にリンクする。
- PC幅で固定CTAが表示されない。
- 商品・価格・相談コピーの既存回帰テストが通る。
