# サバイブ

飯能市を中心に、日高市・入間市周辺で、離れて暮らす家族と高齢者の暮らしを支える地域サービスです。必要なことだけを、本人の意思を大切にしながら相談できます。

## 相談できること

- [防災備蓄サポート](https://survive-support-jp.github.io/bousai/)
  - 水・食料・非常用トイレなど、家庭の備蓄を数え、足りない分と置き場所を確認します。
- [親と実家のスポット訪問](https://survive-support-jp.github.io/oyasupport/)
  - 本人の同意を前提に、外観・郵便受け・庭の確認、短時間の軽作業、写真付きの報告を相談できます。
- [AIを生活に](https://survive-support-jp.github.io/ai-living/)
  - 高齢者のスマホ・AIを、連絡、情報確認、迷惑電話対策など実際の生活で使える形に設定・練習します。

## まず読める実用ガイド

[暮らしの実用ガイド](https://survive-support-jp.github.io/guides/)では、防災備蓄、停電時のスマホ、離れて暮らす親の実家確認、怪しいSMSや電話への備えを、家族と本人が順番に確認できます。

## 大切にしていること

- 本人の同意と意思を確認してから進めます。
- 医療・介護・緊急対応・安否保証、資格が必要な工事、金銭や暗証番号の預かりには対応しません。
- 対応地域や内容を確認し、できること・できないこと、見積の考え方を先にお伝えします。

運営者・連絡先は[運営者情報](https://survive-support-jp.github.io/operator.html)をご覧ください。
